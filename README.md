## 📚 Learning Path — Striver's A2Z DSA Sheet

Solutions in this repository are organized following **Striver's A2Z DSA Sheet**, covering:

| Category | Topics |
|---|---|
| **Fundamentals** | Arrays, Sorting, Binary Search, Strings |
| **Linear Structures** | Linked Lists, Stack & Queue |
